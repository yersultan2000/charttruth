    The AI reads. The math decides.
    Asking a chatbot “is this chart misleading?” gets you an opinion you can’t check. ChartTruth splits the job so every verdict can be traced back to numbers.
    
    
      
      
    1. AI reads the chart
      Gemini or Claude turns pixels into strict JSON: chart type, axis range, tick labels, values and visual cues. In cross-check mode, both read it and must agree.
      AI step, with a confidence score
      2. 
      
    2. A person checks it
      Every number is editable, with undo. Below 60% confidence, or when the two models disagree, the app refuses to judge until someone verifies.
      Human in the loop
      3. 
      
    3. Rules make the call
      Lie factor, tick spacing, slice sums, flipped axes, dual axes and 3D, plus a guardrail for honest zoomed charts.
      Deterministic: same input, same verdict
      4. 
      
    4. It redraws honestly
      Zero baseline, even ticks, upright axis, flat 2D, pies rescaled to 100%, with an honest caption and alt text.
      Output you can share
      5. 
    
    
    
    
      
    Asking an AI directly
    • The answer can change from run to run
    • Can’t show why, beyond a confident paragraph
    • Tends to over-flag any axis that doesn’t start at zero
    • Can’t be corrected when it misreads a number
    
      
    ChartTruth
    • The same numbers always give the same verdict
    • Every flag shows its calculation
    • A guardrail keeps honest science charts from being flagged
    • Fix a misread value and the verdict updates live

    Our standards
    A tool that calls things misleading has to hold itself to a higher bar.
    
    
    
      
    It refuses to guess.
    Below 60% confidence, when two models disagree, or for chart types it doesn’t support, it says “unable to verify”.
    
      
    It avoids false accusations.
    Zoomed line charts in science and finance get a neutral context label, never a misleading flag.
    
      
    It judges design, not people.
    A flag means the visual encoding distorts the numbers. It never claims anyone meant to deceive.
    
      
    People stay in control.
    Every value is editable with undo, and a person can mark the data as checked.
    
      
    Private by default.
    No backend and no tracking. Images go to an AI only with your own key, kept for this tab at most.
    
      
    Accessible.
    Plain-language alt text, keyboard shortcuts, a keyboard-operable compare slider, dark mode and reduced motion.
    
      
    Honest about limits.
    One series at a time. It won’t catch cherry-picked ranges, misleading captions or bad source data.
    
      
    Open method.
    The lie factor is the ratio form of Edward Tufte’s idea. Rules, prompts and benchmark code are all public.
