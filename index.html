    The AI reads. The math decides.
    
  
    Asking a chatbot “is this chart misleading?” gets you an opinion you can’t check. ChartTruth splits the job: a vision model only transcribes, and a small set of published rules makes the call.
    
  
      
    
    1. Gemini reads the chart
      Turns pixels into strict JSON: chart type, axis range, tick labels, values and visual cues.
      AI step · gives a confidence score
      2. 
    
    2. A person checks it
      Every number is editable. Below 60% confidence the app refuses to judge until someone verifies.
      Human-in-the-loop
      3. 
    
    3. Rules make the call
      Lie factor, tick spacing, slice sums, flipped axes, dual axes, 3D, plus a guardrail for honest zoomed charts.
      Deterministic, same input → same verdict
      4. 
    
    4. It redraws honestly
      Zero baseline, even ticks, upright axis, flat 2D, pies rescaled to 100%, with a caption and alt text.
      Output you can share
      5. 
  
    
  
    
    
    Asking an AI directly
    • Answer changes from run to run
    • Can’t show why, beyond a confident paragraph
    • Tends to over-flag any axis that isn’t at zero
    • Can’t be corrected when it misreads a number
    
    
    ChartTruth
    • Same numbers always give the same verdict
    • Every flag shows its calculation
    • Guardrail keeps honest science charts from being flagged
    • You fix a misread value and the verdict updates live

    Standards
    
  
    
    
    It refuses to guess.
    Below 60% extraction confidence, or for chart types it doesn’t support, ChartTruth says “unable to verify” instead of inventing an answer.
    
    
    It avoids false accusations.
    Zoomed line charts are often legitimate. Science and finance line charts get a neutral context label, never a misleading flag.
    
    
    “Misleading” describes the design, not the author.
    A flag means the visual encoding distorts the numbers. It never claims anyone meant to deceive.
    
    
    People stay in control.
    Every extracted value is editable, and a person can mark the data as checked.
    
    
    Nothing leaves your device by default.
    No backend and no tracking. An image goes to Google’s API only when you add your own key, which is kept for this tab at most.
    
    
    Accessible by default.
    Every correction comes with plain-language alt text and an honest caption, and the compare slider works from the keyboard.
    
    
    What it can’t see.
    One data series at a time. It won’t catch cherry-picked date ranges, misleading captions, missing context or bad source data, and vision models can misread small text.
    
    
    About the lie factor.
    This is the ratio form of Edward Tufte’s idea: how many times bigger the largest bar looks than the smallest, divided by how many times bigger it really is.
